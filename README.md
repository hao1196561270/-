# Windows 自动连点器（Auto Clicker）

一个用 **Rust** 编写的 Windows 鼠标 / 键盘自动连点工具，带有图形界面。你可以用它来自动重复点击鼠标、设置点击速度，并通过一个快捷键随时开启或停止，非常适合游戏刷图、重复操作、自动化测试等场景。

> 仓库名：`windows-auto-clicker` ｜ 仅支持 Windows 系统。

## 项目介绍

这个工具的目标是「好用、稳定、不吃资源」。它使用 Rust 语言开发，界面基于 `egui`，打包后只有一个 `auto_clicker.exe`，不需要安装、不需要任何运行环境（不需要装 Python、不需要装 .NET）。

最关键的一点是：**即使连点器窗口本身处于最前方（被你点中、正在看它），快捷键依然能正常触发**。很多同类工具在窗口聚焦时会失灵，本项目通过使用 Windows 的 Raw Input 机制从底层读取键盘，彻底避免了这个问题。

## 功能说明

- **自定义点击间隔**：可以设置每次点击之间相隔多少毫秒（例如 100 毫秒就是每秒点 10 次）。
- **自定义点击次数**：可以设置总共点多少次；填 `0` 表示无限点击，直到你手动停止。
- **选择鼠标按键**：支持左键、右键（也可在代码中扩展中键）。
- **自定义切换键**：用一个快捷键来「开始 / 停止」连点。默认是 `F7`，你可以在软件界面里改成任意按键。
- **全局热键（焦点无关）**：无论连点器窗口是否被点中、是否被最小化，快捷键都能正常生效。
- **轻量无依赖**：单文件 exe，无需安装，开箱即用。

## 安装步骤

### 方式一：下载现成程序（推荐，最简单）

1. 打开本项目的 **Releases** 页面（仓库主页右侧「Releases」或下方的「发行版」）。
2. 下载最新版本里的 `auto_clicker.exe`。
3. 双击 `auto_clicker.exe` 即可运行，不需要安装任何东西。

> 说明：如果 Windows 弹出「已保护你的电脑」之类的 SmartScreen 提示，这是因为程序没有代码签名，属于正常现象，选择「仍要运行」即可。

### 方式二：自己从源码编译

适合想看代码、改功能，或者希望自己构建的同学。

1. 安装 Rust 工具链：访问 <https://www.rust-lang.org> 下载并安装（安装时勾选添加到 PATH）。
2. 确认已安装 **Windows SDK**（用于编译图标资源，通常装了 Visual Studio 或 Windows 10/11 SDK 即可）。
3. 在项目目录里执行编译命令：

```bash
cargo build --release
```

4. 编译完成后，程序在：

```text
target/release/auto_clicker.exe
```

## 使用方法

1. 启动 `auto_clicker.exe`，会弹出一个图形窗口。
2. 在窗口里设置：
   - **点击间隔（毫秒）**：比如填 `200` 表示每 0.2 秒点一次。
   - **点击次数**：填 `0` 表示一直点到你停止；填具体数字表示点够次数自动停。
   - **鼠标按键**：选择左键或右键。
   - **切换按键**：默认 `F7`，点「重新绑定」后按下你想用的键即可。
3. 点击窗口里的「开始」按钮，或者按下你设置的切换键（默认 `F7`）开始连点。
4. 想停下来时，再按一次切换键，或点「停止」。

> 小贴士：连点开始后再去操作其他窗口即可，连点器会在后台按设定节奏点击当前鼠标所在位置。

## 常见问题（FAQ）

**Q：为什么我按下切换键没反应？**
A：请确认连点器窗口是否已经正常启动；切换键默认是 `F7`，可在界面中重新绑定。若你改过键，按新键即可。另外请确认没有其他软件（如游戏内快捷键、输入法）占用同一个按键。

**Q：为什么有些游戏里不点？**
A：部分游戏以管理员权限运行，此时连点器也需要以管理员身份运行才能向其窗口发送输入。请右键 `auto_clicker.exe` 选择「以管理员身份运行」。

**Q：窗口被我点中（聚焦）时，快捷键还能用吗？**
A：能。本项目使用 Raw Input 从系统底层读取键盘，无论窗口是否聚焦、是否最小化，切换键都正常工作。

**Q：支持中键 / 键盘按键连发吗？**
A：当前界面支持左键、右键；代码结构已预留扩展，后续可增加中键和键盘连发。

**Q：会被识别为病毒吗？**
A：这是你自己可审查的开源程序，不含任何恶意代码。没有代码签名会被系统误报属正常现象。

**Q：我想改默认图标 / 界面，怎么做？**
A：图标由 `tools/make_icon.py` 生成 `assets/icon.ico`，界面布局在 `src/ui.rs`。修改后重新编译即可。

## 目录结构

| 路径 | 作用 |
|------|------|
| `src/main.rs` | 程序入口，创建窗口和共享状态 |
| `src/clicker.rs` | 后台连点线程，按配置发送鼠标输入 |
| `src/hotkey.rs` | 基于 Raw Input 的全局键盘监听与切换键捕获 |
| `src/state.rs` | 共享配置状态（点击间隔、次数、按键等） |
| `src/ui.rs` | `egui` 图形界面与交互逻辑 |
| `src/input.rs` | 发送鼠标 / 键盘输入的封装 |
| `build.rs` | 编译时把图标嵌入 exe |
| `assets/` | 图标资源（icon.ico / icon.png） |
| `tools/make_icon.py` | 生成图标的小工具 |

## 技术说明（简要）

- 平台：Windows
- 语言：Rust
- 界面：`eframe` + `egui`
- 全局热键：Windows **Raw Input**（`RegisterRawInputDevices` + `WM_INPUT`），相比传统低级键盘钩子，在窗口聚焦时也能可靠触发
- 输入发送：Windows `SendInput`
